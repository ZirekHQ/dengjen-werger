== Funding

Tasks 7–15 above (Crowdin write path through `JobsService` reminders) are
budgeted as *M0 — Translator Recruitment Infrastructure* in the Zirek
NLnet General Open Call proposal (draft: `nlnet-proposal.md` in the
`zirekhq` workspace root), €5,400 / 90 hours, months 1–2 of a 6-month grant
if awarded. Rationale: nvdaku's translation has been open since 2018 and is
still partial because one-off volunteer offers don't sustain, not for lack
of a translation tool — this is the actual mechanism to fix that, not scope
adjacent to the grant's real goal.

Explicitly out of the funded scope (deferred past M0, not committed to any
timeline): `PointsRepo`, `StreakCalculator`/`TrustLevel`, `ApprovalService`'s
trust gate, `AccountDeletionService`, and all of Milestone 3
(contributor-facing API/SPA) — an admin-triggered CLI/API is sufficient to
run the first recruitment cohort. Everything beyond nvdaku/Crowdin/NVDA
(Beyond v1 section above) remains unfunded and unscheduled.

If the NLnet application is not funded, this section reverts to being an
open call on the maintainer's time — revisit before the Nov 3, 2026
deadline result.
